# Embedded Engineering

A personal repository for practicing and improving Embedded C/C++ programming through small projects, coding exercises, and continuous refinement.

## Purpose

The goal of this repository is to build strong engineering habits rather than simply solving programming problems.

Each implementation focuses on writing code that is:

* Readable
* Maintainable
* Well documented
* Defensive
* Continuously improved through review and refactoring

As this repository grows, it will reflect my ongoing learning and engineering experience in Embedded Software Development.

## Repository

Each directory contains one or more self-contained implementations or exercises focused on a specific topic.

Every project is treated as an opportunity to practice software engineering principles, not just produce a working solution.

# C

This directory contains small C programming exercises and implementations created as part of my Embedded Software Engineering practice.

The focus is not only on producing a working solution, but also on developing good engineering habits, including:

* Writing clean and maintainable code.
* Considering edge cases and defensive programming.
* Reviewing and refining implementations.
* Continuously improving code quality through practice.

Each exercise may include its own documentation describing the problem, implementation, design decisions, and lessons learned.

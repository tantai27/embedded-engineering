# Bit Rotate

A lightweight Embedded C module for rotating the bits of an 8-bit unsigned value to the left or right.

Unlike a normal bit shift, bit rotation preserves all bits by moving the bits shifted out from one side back to the opposite side.

The module provides:

- Left bit rotation.
- Right bit rotation.
- Automatic normalization of the rotation amount to the 8-bit width.
- Hardware-independent implementation.
- No dynamic memory allocation.

The module is designed to practice bitwise operations, unsigned integer handling, shift boundary conditions, and defensive low-level Embedded C programming.
